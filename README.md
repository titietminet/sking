# sking

Un prototype Next.js pour explorer des recommandations de skis et de fixations à partir du profil et du budget du skieur.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

Les setups affichés sont des exemples de démonstration. Le catalogue, les règles de recommandation et la compatibilité des fixations devront être reliés à des données produit fiables avant une mise en production.
